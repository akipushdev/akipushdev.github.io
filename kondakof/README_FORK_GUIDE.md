# Инструкция по переносу и запуску лендинга KONDAKOF

Данный репозиторий содержит готовый лендинг архитектурного освещения **KONDAKOF** с интерактивным опросником, сквозными UTM-метками, установленной Яндекс Метрикой и автоматической отправкой заявок прямо в Telegram Дмитрию Кондакову.

Исходный репозиторий: [https://github.com/akipushdev/akipushdev.github.io](https://github.com/akipushdev/akipushdev.github.io)

---

## 1. Как забрать проект к себе (Fork)

Репозиторий публичный, но защищён от прямой записи — вы не можете случайно сломать оригинал, но можете сделать полную независимую копию к себе в аккаунт:

1. Перейдите по ссылке: [https://github.com/akipushdev/akipushdev.github.io](https://github.com/akipushdev/akipushdev.github.io)
2. В правом верхнем углу страницы нажмите кнопку **Fork**.
3. В открывшемся окне:
   - В поле **Repository name** укажите удобное имя, например: `kondakof-site` (или `kondakof.com`).
   - Нажмите зелёную кнопку **Create fork**.
4. Теперь у вас в аккаунте GitHub есть собственная копия проекта, где вы являетесь полным владельцем и администратором.

## 3. Настройка домена `kondakof.com` на GitHub Pages

GitHub Pages предоставляет бесплатный хостинг с автоматическим SSL-сертификатом (HTTPS).

### Шаг 3.1. Настройка в репозитории GitHub:
1. В вашем форкнутом репозитории перейдите в **Settings** (вкладка сверху).
2. В левом боковом меню выберите **Pages** (раздел *Code and automation*).
3. В блоке **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: выберите ветку `main` и папку `/ (root)`
   - Нажмите **Save**.
4. В блоке **Custom domain**:
   - Введите: `kondakof.com`
   - Нажмите **Save** (GitHub создаст файл `CNAME` и начнет проверку DNS).
5. Поставьте галочку **Enforce HTTPS** (станет активна после того, как обновятся DNS-записи, обычно через 5–15 минут).

### Шаг 3.2. Настройка DNS у регистратора домена:
В панели управления, где куплен домен `kondakof.com` (Reg.ru, Namecheap, Beget и т.д.), перейдите в раздел **Управление DNS** и добавьте записи:

1. **A-записи для основного домена (`@`):**  
   Создайте 4 A-записи, указывающие на IP-адреса GitHub:
   - Хост: `@` | Значение: `185.199.108.153`
   - Хост: `@` | Значение: `185.199.109.153`
   - Хост: `@` | Значение: `185.199.110.153`
   - Хост: `@` | Значение: `185.199.111.153`

2. **CNAME-запись для поддомена `www`:**
   - Хост: `www` | Значение: `ваш_аккаунт_github.github.io.` (с точкой на конце, если требует регистратор).

## 4. Как работает приём заявок (Telegram CRM)

В форме **уже всё настроено и работает**:
- При заполнении брифа пользователю **не нужно** переходить в приложение Telegram или нажимать Enter.
- Скрипт в браузере асинхронно отправляет запрос в Telegram Bot API.
- Сообщение моментально доставляется **лично Дмитрию Кондакову** (`chat_id: 332066778`) через бота `@Automaticnodered_bot`.

## 5. Яндекс Метрика и цели конверсии

На сайте уже установлен счетчик **Яндекс Метрики**: `113591050`.

В коде реализована отправка двух JavaScript-целей:
1. **`open_modal`** — фиксирует интерес (пользователь нажал любую из кнопок: «Рассчитать для дома», «Заказать аудит», «Получить эскиз»).
2. **`lead_success`** — главная конверсия (заявка успешно ушла в Telegram). По этой цели настраивается авто-стратегия с оплатой за лиды в Яндекс Директ.

Если создадите свой собственный счетчик в [metrika.yandex.ru](https://metrika.yandex.ru), просто замените число `113591050` на ваш номер в `index.html` (в шапке `<head>` и в функциях `openBriefModal` и `handleBriefSubmit`).

## 6. Как запускать рекламу с UTM-метками

Сайт умеет автоматически вытаскивать любые UTM-метки из адресной строки и передавать их в Telegram.

Шаблон ссылки для рекламы (Яндекс Директ / Telegram / посевы):
```text
https://kondakof.com/?utm_source=yandex&utm_medium=cpc&utm_campaign=msk_novariga&utm_content=sketch24h&utm_term=podsvetka_doma
```
Параметры:
- `utm_source` — рекламный канал (`yandex`, `telegram`, `vk`, `partner`)
- `utm_medium` — формат (`cpc` — клики, `post` — пост, `banner` — баннер)
- `utm_campaign` — название кампании / поселка (например, `msk_novariga` или `minsk_raubichi`)
- `utm_content` — вариант креатива / оффера
- `utm_term` — ключевое слово
